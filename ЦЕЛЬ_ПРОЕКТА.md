# Цель приложения «Расписание ИОЗ-231»

> Надёжное и бесплатное расписание ИОЗ-231 на iPhone и в браузере: автоматически показывать подтверждённые изменения и открыто обозначать то, что проверить не удалось.

## Для пользователя
- Открыть сайт без регистрации и сразу увидеть пары на выбранный день.
- Увидеть статус базовой таблицы, VK и возможные непроверенные изменения.
- При переносе или отмене перейти к объявлению-источнику.
- Если проверка VK или Excel не удалась, видеть предупреждение, а не ложное «всё актуально».

## Для системы
- Обрабатывать только ИОЗ-231, включая действительно общие занятия.
- Применять только однозначные изменения, не домысливать и не удалять исходник.
- Сохранять последнюю подтверждённую версию и историю источников.
- Работать бесплатно на GitHub Actions + Pages, без включённого личного устройства.

## Что ещё не готово
- Чтение реальных постов требует токена VK и живого тестирования.
- Изображения и сложные объявления без проверки распознавать нельзя.
- Длительные сбои GitHub и смену семестра необходимо отслеживать.
- Отметка времени успешной проверки каждого источника требует доработки.
